# KNS Construction & Real Estate — Client-photo React website

This version uses the client-supplied KNS photographs saved locally in `public/images`. It does not rely on remote stock-photo URLs for the project gallery or hero imagery.

## Run locally
1. Extract the ZIP.
2. Open the `KNS-Client-Website` folder in VS Code.
3. Open Terminal > New Terminal.
4. Run:
   ```bash
   npm install
   npm run dev
   ```
5. Open the local URL Vite prints, usually `http://localhost:5173`.

## Production build
```bash
npm run build
npm run preview
```
